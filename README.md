# TAKE IT — Food Delivery App

A full-stack food delivery application built using React and Spring Boot.

## Tech Stack

- Frontend: React, Vite, Tailwind CSS
- Backend: Java, Spring Boot, Spring Data JPA
- Database: MySQL
- API: REST APIs

## Features

- User registration and login
- Restaurant and dish browsing
- Restaurant owner dish management
- Cart and checkout
- Order placement and order history
- Razorpay test payment and Cash on Delivery

## Project Structure

- `frontend/` — React application
- `backend/` — Spring Boot REST API
- `database/` — Demo SQL data

## Setup

1. Clone the repository.
2. Create a local MySQL database.
3. Import `database/sample-data.sql` after the schema is created.
4. Configure local environment variables.
5. Run the Spring Boot backend.
6. Install frontend dependencies with `npm install`.
7. Start the frontend with `npm run dev`.

## Security

No production API keys, passwords, or private environment files are included.
